# Day 3 TL-Verilog Codes

This directory contains all TL-Verilog implementations developed during Day 3 of the RISC-V MYTH Workshop.

## Implementations

- Logic Gates
- Multiplexer
- Combinational Calculator
- Sequential Calculator
- Counter
- Counter + Calculator Pipeline
- Error Detection Pipeline
- Two-Cycle Calculator
- Calculator with Validity
- Calculator with Single Value Memory
- 3D Distance Calculator using Pythagoras Theorem

All implementations were developed and verified using Makerchip IDE.
